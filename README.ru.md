# Scene Agent Skills

**Открытый набор навыков и инструментов для архитектурных сцен — от изображения и плана до проверяемого результата.**

[English](README.md) · [Установка](docs/installation.md) · [16 стилей](docs/style-catalogue.md) · [20 навыков](docs/skills.md) · [Что проверено](docs/verification.md)

Репозиторий для архитекторов, визуализаторов и разработчиков, работающих с **Codex / Astra и Claude Code**. Здесь собраны инструкции для агентов, исполняемые инструменты и примеры. Всё оригинальное содержимое распространяется бесплатно по лицензии MIT, в том числе для коммерческого использования с сохранением условий лицензии.

## Быстрый старт в Windows

Нужен Python 3.11 или новее. В PowerShell:

```powershell
git clone https://github.com/prorenderbureau/scene-agent-skills.git
cd scene-agent-skills
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[camera,bim,mcp]"
.\.venv\Scripts\scene-agent.exe styles
.\.venv\Scripts\scene-agent.exe plan-check examples/courtyard/plan.json
.\.venv\Scripts\scene-agent.exe ifc examples/courtyard/plan.json --out outputs/courtyard.ifc
.\.venv\Scripts\scene-agent.exe corona --quality preview --out outputs/corona-preview.ms
```

Команда IFC создаёт настоящий файл модели. Команда Corona создаёт скрипт, который затем запускается в 3ds Max. Просмотр стилей выдаёт рецепты, а не генерирует картинки. Готовые файлы не перезаписываются автоматически: для новой версии укажите новое имя.

Для macOS/Linux активируйте окружение через `source .venv/bin/activate` и используйте команды `python` и `scene-agent`. Нативные команды 3ds Max требуют Windows и установленной программы.

## Установка навыков

Выберите существующую папку проекта:

```powershell
.\.venv\Scripts\python.exe tools/install_skills.py --agent both --project "C:\Projects\Villa" --dry-run
.\.venv\Scripts\python.exe tools/install_skills.py --agent both --project "C:\Projects\Villa"
```

Первый запуск показывает изменения. Второй копирует общий набор в `.agents/skills` для Codex и `.claude/skills` для Claude. Одинаковые файлы пропускаются; при несовпадающих локальных правках установка останавливается до копирования. Глобальные настройки и другие проекты не меняются.

В Codex начните с `$scene-toolkit`. Можно выбрать конкретный навык, например `$scene-camera-match` или `$scene-corona-materials`.

В Claude Code доступны плагины:

```text
/plugin marketplace add prorenderbureau/scene-agent-skills
/plugin install scene-agent-skills@scene-agent-skills
/scene-agent-skills:scene-toolkit
```

Для проверки локального клона: `claude --plugin-dir /полный/путь/к/scene-agent-skills`. Установка плагина не устанавливает Python, 3ds Max, Corona или Archicad. Выберите один способ подключения навыков, чтобы не получить дубликаты.

## Примеры заданий агенту

**Реконструкция сцены:**

> Используй $scene-toolkit. Собери редактируемую сцену по этим изображениям, первое — главный ракурс. Сохрани окна и этажность. Известная ширина фасада 12 метров. Сначала сделай блокинг и камеру, затем материалы и свет. Покажи настоящий рендер и перечисли, какие размеры восстановлены предположительно.

**Стилизация:**

> Используй $scene-style-transfer. Сделай варианты blue-hour, japandi и clay-study. Геометрия и камера должны оставаться одинаковыми. Мне нужны изображения; отдельно укажи, какие изменения существуют в 3D-сцене, а какие сделаны только в изображении.

**План для Archicad:**

> Используй $scene-plan-to-bim. На плане указан размер 8 метров. Подготовь проверенный JSON и IFC со стенами, плитой, дверями и окнами. Проёмы должны реально вырезаться в стенах. Сохрани источник масштаба и составь список проверок после импорта в Archicad.

## Стили

Шесть вариантов освещения: фотореалистичный дневной, синий час, золотой час, мягкая пасмурная погода, дождливый кинематографичный и архитектурная ночь.

Семь направлений дизайна: скандинавский, Japandi, тёплый минимализм, фактурный брутализм, современный средиземноморский, индустриальный лофт и тропический биофильный.

Три способа подачи: clay, акварельная концепция и техническая аксонометрия. Акварель — отдельная иллюстративная обработка; специального «акварельного переключателя Corona» здесь нет.

## Что важно понимать

Это версия **0.1.0**, основа рабочего процесса и будущей платформы. Она не содержит обученной модели, которая самостоятельно и безошибочно превращает любое изображение в полную 3D-сцену. Изображение, редактируемая сцена и BIM-модель — разные результаты.

Распознавание и обводка исходного плана выполняются агентом с подходящими инструментами или человеком. Экспортёр принимает проверенный JSON: прямые стены, прямоугольные плиты и проёмы, несколько этажей. Он не строит автоматически произвольные крыши, инженерные системы и лестницы.

IFC проверяется программно: типы элементов, единицы, связи проёмов и реальные объёмы геометрии. **Импорт в нативный Archicad и сохранение PLN на рабочей станции автора не проверены.** После импорта нужно убедиться, что получены нужные редактируемые элементы, а не только Morph/Object, и проверить обратный экспорт.

Расчёт камеры требует известных точек в 3D и их пиксельных координат, начального приближения и неплоского набора опорных точек. Текущая версия не вычисляет дисторсию и сдвиг оптического центра. Низкая ошибка на точках не доказывает точность невидимой части здания.

Настройки low/high/very-high относятся к модели, а preview/review/final — к рендеру. Больше полигонов не исправляет неверную камеру, плохую фактуру или ошибочный свет. Крупность детали в итоговом кадре определяет, куда разумно тратить вычисления.
