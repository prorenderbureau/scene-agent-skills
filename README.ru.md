# Scene Agent Skills

**Бесплатные навыки для Codex и Claude: подбор камеры, 16 стилистик рендера, настройка Corona и создание IFC-моделей по структурированным планам.**

[English](README.md) · [Начать работу](docs/installation.md) · [16 стилей](docs/style-catalogue.md) · [20 навыков](docs/skills.md) · [Результаты тестов](docs/verification.md)

Дайте своему агенту готовый порядок работы над архитектурной сценой. **Scene Agent Skills** объединяет 20 навыков, исполняемые инструменты и оригинальные примеры для архитекторов и визуализаторов, работающих с **Codex / Astra и Claude Code**.

Выберите стилистику, сохраните архитектуру и ракурс, задайте детализацию и переходите к материалам, свету и подготовке проекта к передаче. Скрипты помогают повторять настройки, а подключённые к агенту программы создают итоговые изображения и сцены.

**Бесплатно по лицензии MIT, включая коммерческое использование с соблюдением её условий.** Можно начать с одного навыка или установить весь набор в свой проект.

## Быстрый старт в Windows

Нужен Python 3.11 или новее. В PowerShell:

```powershell
git clone https://github.com/prorenderbureau/scene-agent-skills.git
cd scene-agent-skills
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[camera,bim,mcp]"
.\.venv\Scripts\scene-agent.exe styles
.\.venv\Scripts\scene-agent.exe plan-check examples/courtyard/plan.json
.\.venv\Scripts\scene-agent.exe ifc examples/courtyard/plan.json --out outputs/courtyard.ifc
.\.venv\Scripts\scene-agent.exe corona --quality preview --out outputs/corona-preview.ms
```

Эти команды создают IFC-модель и скрипт настройки Corona, а также открывают каталог рецептов стилизации. Запустите MAXScript в 3ds Max, а выбранный рецепт примените через подключённый инструмент работы с изображениями или 3D. Для каждой версии указывайте новое имя файла, чтобы сохранить предыдущий результат.

Для macOS/Linux активируйте окружение через `source .venv/bin/activate` и используйте команды `python` и `scene-agent`. Нативные команды 3ds Max требуют Windows и установленной программы.

## Установка навыков

Выберите существующую папку проекта:

```powershell
.\.venv\Scripts\python.exe tools/install_skills.py --agent both --project "C:\Projects\Villa" --dry-run
.\.venv\Scripts\python.exe tools/install_skills.py --agent both --project "C:\Projects\Villa"
```

Первый запуск показывает изменения. Второй копирует общий набор в `.agents/skills` для Codex и `.claude/skills` для Claude. Одинаковые файлы пропускаются; при несовпадающих локальных правках установка останавливается до копирования. Глобальные настройки и другие проекты не меняются.

В Codex начните с `$scene-toolkit`. Можно выбрать конкретный навык, например `$scene-camera-match` или `$scene-corona-materials`.

В Claude Code доступны плагины:

```text
/plugin marketplace add prorenderbureau/scene-agent-skills
/plugin install scene-agent-skills@scene-agent-skills
/scene-agent-skills:scene-toolkit
```

Для локального клона: `claude --plugin-dir /полный/путь/к/scene-agent-skills`. Установите Python и программы, нужные для выбранного процесса: 3ds Max, Corona или Archicad. Выберите один способ подключения навыков, чтобы избежать дубликатов.

## Примеры заданий агенту

**Реконструкция сцены:**

> Используй $scene-toolkit. Собери редактируемую сцену по этим изображениям, первое — главный ракурс. Сохрани окна и этажность. Известная ширина фасада 12 метров. Сначала сделай блокинг и камеру, затем материалы и свет. Покажи настоящий рендер и перечисли, какие размеры восстановлены предположительно.

**Стилизация:**

> Используй $scene-style-transfer. Сделай варианты blue-hour, japandi и clay-study. Геометрия и камера должны оставаться одинаковыми. Мне нужны изображения; отдельно укажи, какие изменения существуют в 3D-сцене, а какие сделаны только в изображении.

**План для Archicad:**

> Используй $scene-plan-to-bim. На плане указан размер 8 метров. Подготовь проверенный JSON и IFC со стенами, плитой, дверями и окнами. Проёмы должны реально вырезаться в стенах. Сохрани источник масштаба и составь список проверок после импорта в Archicad.

## Стили

Шесть вариантов освещения: фотореалистичный дневной, синий час, золотой час, мягкая пасмурная погода, дождливый кинематографичный и архитектурная ночь.

Семь направлений дизайна: скандинавский, Japandi, тёплый минимализм, фактурный брутализм, современный средиземноморский, индустриальный лофт и тропический биофильный.

Три способа подачи: clay, акварельная концепция и техническая аксонометрия. Для каждого варианта есть рекомендации по подготовке и проверке; акварель выполняется как иллюстративная обработка.

## Выберите задачу

- **Изображение → сцена:** разберите размеры и перспективу, подберите камеру, затем постройте модель и выполните рендер в подключённой 3D-программе.
- **Изображение → варианты стилистики:** выберите рецепт, зафиксируйте архитектуру и камеру, примените его через инструмент работы с изображениями или 3D.
- **План → BIM:** выполните обводку с агентом или оператором, проверьте структурированный план, создайте IFC и следуйте инструкции импорта в Archicad.

В [руководстве по инструментам](docs/capabilities.md) описаны входные данные, результаты и нужные программы. Для моделирования предусмотрены профили low/high/very-high; для качества рендера — preview/review/final.
